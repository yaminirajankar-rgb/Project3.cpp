Project 3 - Interactive Calculator

This project is a C++ interactive calculator.

## Features
- Addition, subtraction, multiplication and division
- Modulus and power operations
- Runs continuously until the user quits
- Stores the last 10 calculations
- Displays calculation history
- Handles invalid input
- Handles division by zero without crashing

## How to Run
Compile the Project3.cpp file using a C++ compiler and run the generated program.

## Commands
- Enter a calculation like: 10 + 5
- Enter h to view history
- Enter q to quit
